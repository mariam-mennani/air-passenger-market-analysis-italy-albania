# Air Passenger Market Analysis (Italy – Albania Route)

## Overview
This project analyzes passenger traffic trends between Italy and Albania using Eurostat data.  
The goal is to evaluate demand evolution, seasonality, and post-COVID recovery, and to provide a simple traffic forecast.

## Key Insights
- Strong post-COVID recovery with +56% CAGR
- Stable long-term growth (Total CAGR: 16.5%)
- High volatility driven by COVID shock (49%)
- Peak month demand ~20% above average → strong seasonality

## Analysis Performed
- Data cleaning and restructuring (Eurostat dataset)
- Year-over-Year (YoY) growth analysis
- CAGR (Total, Pre-COVID, Post-COVID)
- Volatility analysis (standard deviation)
- Seasonality analysis (monthly patterns)
- Peak Month Ratio calculation
- Traffic trend visualization and forecasting
